# Дневник питания и силы

Кидай фото еды в чат агента Cursor (подойдёт и Grok). Агент спросит время, допишет строку в `log.csv` и даст короткий разбор КБЖУ.

## Файлы
| Файл | Зачем |
|------|--------|
| `profile.md` | Кто ты: вес, быт, цели, ориентиры |
| `training.md` | Зал, цикл, прошлые максимумы |
| `supplements.md` | Добавки |
| `log.csv` | Лог еды: день, время, приём, КБЖУ |
| `daily_notes.md` | Итоги дня |

## Быстрые команды в чате
- фото + время → запись в лог
- `сегодня` / `вчера` / `неделя`
- `исправь ...` / `удали последнюю`
- `профиль` / `тренировка`

## Модель
Для экономии можно Grok: файлы и структуру ведёт нормально. Оценка порций по фото чуть грубее, чем у Opus/GPT — при сомнении уточняй граммы.
